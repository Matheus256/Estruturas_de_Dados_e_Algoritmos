<h1>Estruturas de Dados e Algoritmos</h1>

Repositório destinado a disciplina de Estruturas de Dados e Algoritmos do Curso de Engenharia da Computação. 
Aqui estão algumas atividades e implementações discutidas durante o curso. 
Também foram acrescentados alguns desafios e questões das atividade avaliativas (as famosas provas). 

<h2>Fundamentos de C</h2>

O curso foi desenvolvido na linguagem de programação ```C```, dessa forma contou com um módulo para estudar os fundamentos
dessa linguagem de programação. Portanto, sobre a linguagem C foram estudados em detalhes:

- Entrada e saída
- Estruturas condicionais e de repetição
- Strings
- Matrizes
- Structs
- Ponteiros
- Funções

<h2>Estruturas de Dados</h2>

Com o domínio da linguagem C, o passo seguinte foi estudar e implementar as seguintes estruturas de dados:

- Listas sequenciais
- Listas simplesmente encadeadas
- Listas duplamente encadeadas
- Pilhas
- Filas
- Árvores binárias (de busca)

<h2>Algoritmos de Ordenação</h2>

Por fim, foram estudados e implementados alguns algoritmos de busca, tais como:

- Bubble sort
- Insertn sort
- Selection sort
